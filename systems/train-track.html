The Architecture

I built this system to allow level designers to drag and drop train tracks seamlessly across a map. Instead of placing static meshes manually, this system runs in the OnConstruction script, dynamically generating the track along a USplineComponent in real-time as the user moves spline points.


// Optimization: Using HISM for Draft Mode to save editor performance

Core Features

  • Dynamic Stretching: Automatically calculates the amount of meshes that fit inside the spline and mathematically stretches them to prevent gaps.
  • Spline Banking & Roll: Extracts local rotation data from the spline points to bank the track accurately around sharp turns.
  • Tangent Clamping: Prevents extreme mesh distortion by clamping tangents to the target mesh length.

Technical Spotlight: Optimization

The Problem: Generating dozens of USplineMeshComponents recalculates complex collision and rendering data, which can heavily tank editor performance when dragging a spline.

The Solution: I engineered a Draft Mode. When enabled, it clears the Spline Meshes and spawns a single UHierarchicalInstancedStaticMeshComponent. This allows level designers to block out miles of track with zero lag, disabling draft mode only when finalizing the level.
